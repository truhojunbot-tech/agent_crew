**Chosen multilingual model_id:**
`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`.
It is the highest-scoring multilingual candidate whose measured p95 retrieval
latency is at most 300 ms. The control and baseline are excluded from model
selection. This is a provisional choice: it did not improve owner recall over
lexical retrieval on this snapshot, and task recall cannot discriminate models.

**Corpus coverage limit:** all 17 owner cases have at least one exact expected
memory key in the copied DB; none of the 24 task cases has an exact expected
reference as a memory key. Thus `0/24` records a missing source corpus, not
24 demonstrated ranking failures. The task cases include issue/PR and
blackboard references that this DB does not store. A later task-recall
comparison needs those records in a frozen, scoped corpus.

Method: A2 `HybridMemoryStorage.retrieve_ranked` with `MemoryScope(project=...)`,
`k=10`, a 65,536-byte middle budget, its normal head and lazy-vector behavior,
and its 300 ms retrieval deadline. A case counts as a hit when any expected
key appears exactly in the returned head or middle. P95 uses the nearest-rank
41-query sample; embed timing includes tokenization and ONNX CPU inference.
The ONNX weights and tokenizers live in caches outside the repo. E5 uses its
query/passage prefixes; controls use their normal input text. Fallback counts
were 4 (E5), 0 (multilingual MiniLM), 33 (BGE-M3), 0 (English MiniLM), and 0
(lexical). A fallback can exceed the 300 ms deadline, as reflected above.
