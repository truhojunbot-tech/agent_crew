# R5: qmd 2.1.0 on ADR-001 memory (2026-10-11)

This is a retrieval evaluation on an online SQLite backup. No production memory row or server setting was changed. The companion harness is [`scripts/eval_qmd_r5.py`](../scripts/eval_qmd_r5.py).

## Corpus and scope

- Source: `~/.agent_crew/memory/adr001_memory.db`, copied by `sqlite3.Connection.backup()` into `/dev/shm` before export. The copy passed `PRAGMA integrity_check`. Snapshot SHA-256: `398f463c5fd11f4cae282e62cecbcc6ab513e97473de93b9a555ab54543c898f`.
- Frozen set: `adr001_eval_set_20261009.json`, SHA-256 `0bdb218d0c8e6ba3da8202c19201fee52a9605664ebe3ea4fb1d5de92de4ac61`; 17 owner and 24 task cases. The file was read only.
- Effective corpus: 10,279 rows where both `superseded_by` and `invalidated_at` are NULL (978 authoritative, 1,815 decision, 7,309 episodic, 145 failure pattern, 32 procedural). Each row became one Markdown document with key, layer and scope in front matter and its value in the body. Document paths begin with the project scope; fleet rows reside in a separate fleet collection. The index has 22 project collections and one fleet collection. Hardlinks expose the same 42 fleet documents in every project collection so each CLI query can use one native collection filter; content bodies and embeddings are shared by hash.
- Each query searched only its exact project collection (including fleet hardlinks) or the fleet collection when the project was absent. Frozen case `tc-21` uses `agent_council`, which has no exact project collection in this snapshot; the corpus uses `agent-council`. That case searched the fleet collection only. Expected refs were resolved with the existing #676 resolver, then restricted to effective rows in those collections. Under this exact scope, 17/17 owner and 11/24 task cases have at least one expected key available. Missing references are scored as misses.
- Query whitespace was collapsed to one line for qmd's structured MCP search. QMD rejects hyphens as lexical negation syntax in vector queries, so `-term` exclusions were omitted and internal hyphens became spaces in `vsearch` and MCP `vec` subqueries; lexical and hybrid CLI queries kept the original terms. A hit means at least one available expected memory key appears in the top 10. Korean-target means at least one expected row body contains Hangul; this yields 16 Korean-target and one English-target owner case.
- Embedding used qmd 2.1.0 defaults, including regex chunking and the installed GGUF models below; no custom vector implementation was used.

## Isolation and reproducibility

The harness set `INDEX_PATH=/dev/shm/ac_r5_qmd_676/index.sqlite` and `QMD_CONFIG_DIR=/dev/shm/ac_r5_qmd_676/config` for every qmd process, including the MCP server. This uses qmd's installed index and config overrides; `~/.cache/qmd/index.sqlite` was not the benchmark index. The existing shared model cache supplied model files. The temporary SQLite backup, documents, index and config were removed after reporting.

## Results

The table below reports first-run top-10 recall and latency over five repetitions of all 41 cases for completed arms (205 requests each). Incomplete arms are marked explicitly. Cold arms start a qmd CLI process for each request; qmd's disk model and query caches persist between processes. Warm arms call one persistent qmd MCP server. MCP uses typed `lex`/`vec` subqueries; unlike CLI `qmd query`, it does not invoke automatic query expansion, so the warm hybrid figures are a related, not identical, workload.

The cold CLI vector arm was stopped after its first measured request took 14,436.4 ms. Reloading the embedding model for 205 independent CLI processes would exceed this worker's one-hour dispatch lease; no p50/p95 or full-set recall is claimed for that arm. The harness checkpoints every request under its temporary work directory so a longer unattended run can resume the exact remaining samples.

## Interpretation

The warm vector and hybrid arms found owner cases `oc-01`, `oc-02`, `oc-06`, `oc-08`, `oc-12`, `oc-16`, and `oc-17`. The reranker added task cases `tc-01` and `tc-08` to `tc-14`, which vector and non-reranked hybrid search already found. All seven owner hits were Korean-target cases; the sole English-target owner case was missed. Retrieval recall is bounded by corpus coverage, especially 11/24 task cases under exact production scope. Latency excludes the one-time embedding backfill. The low rerank p50 reflects qmd's persistent rerank-score cache across repetitions; the p95 includes uncached calls.
